# Domain Research

## Purpose
Conduct deep-dive domain and industry research. Produces glossaries, domain model outlines, and subject-matter summaries that ground Layer 0 and Layer 1 decisions.

## Inputs
- User research brief or domain/industry topic
- Existing Layer 0 or Layer 1 documents for context

## Outputs
- Research document in layers/layer-0-business/intermediate/ or layers/layer-1-product/intermediate/ depending on topic

## Steps (TODO)
1. Clarify domain scope and key questions
2. Identify key concepts, actors, and terminology
3. Map domain relationships and constraints
4. Synthesize into structured research document
5. Write to appropriate intermediate/ path
