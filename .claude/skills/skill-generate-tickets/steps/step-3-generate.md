# Step 3: Generate Ticket Definitions

**For each ticket:**
- Title: concise action phrase (verb + noun)
- Description: context, scope, and what done looks like
- Acceptance criteria: numbered, testable, specific
- Dependencies: list of other ticket IDs this blocks on
- Labels: layer (backend/frontend/infra), type (feature/chore/spike)
- Separation of concerns note: what is explicitly out of scope for this ticket

Use ticket-template.md as format guide.
